<h1 align="center">Workly</h1>

<p align="center">
  Encuentra y contrata servicios locales, todo desde un mismo lugar.
</p>

---

Workly es una aplicación móvil para encontrar y contratar servicios locales — plomeros, gasistas, notarios, electricistas y más.

La plataforma conecta a dos tipos de usuarios:

- **Empresas**: se registran y publican los servicios que ofrecen.
- **Clientes**: buscan servicios cerca de ellos y los contratan directamente desde la app.

## ✨ Qué puedes hacer en Workly

- Buscar servicios locales por categoría y ubicación
- Ver los servicios que ofrece cada empresa
- Contratar y pagar un servicio directamente desde la app
- Registrar tu empresa y publicar lo que ofreces

## 🛠️ Hecho con

- React Native + Expo
- Firebase
- Stripe
- Google Maps
